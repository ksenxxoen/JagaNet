# Boop 1.4.0 (Windows): служба и окно без прав администратора

* Туннель (AmneziaWG, VLESS, маршруты, DNS, kill switch) теперь в службе `BoopVPN` (LocalSystem).
  Окно запускается без прав администратора и без UAC; VPN не отваливается, если окно закрыто или упало.
* UAC спрашивается один раз — при установке или обновлении службы. Отказ или ошибка: окно пишет об этом,
  «Повторить» запускает установку заново.
* После перезагрузки или перезапуска службы подключение, оставленное включённым, поднимается само.
* Автозапуск: вместо задачи планировщика с высшими правами — ключ `Run` текущего пользователя (`--tray`).
  Включённый автозапуск при обновлении сохраняется.
* Обновление: служба сама скачивает и проверяет (SHA-256, подпись) новую версию и заменяет `%ProgramFiles%\Boop\Boop.exe`.
* Удаление: `Boop.exe --uninstall-service` (с UAC).
* Протокол, параметры обфускации, конфиги VLESS/xray и API панели не менялись.

## Ручная проверка на Windows (обычный пользователь без прав админа)

1. Чистая машина, `Boop.exe` из загрузок: появляется один запрос UAC; затем окно открывается из `%ProgramFiles%\Boop`.
2. Отказ от UAC: сообщение в окне; «Повторить» снова показывает запрос.
3. Подключение AmneziaWG; подключение VLESS (смена протокола пересобирает адаптер).
4. Закрыть окно через крестик (в трей) и через «Выход» с работающим VPN: через крестик VPN остаётся; «Выход» отключает.
5. Завершить процесс окна в диспетчере задач: VPN работает, новое окно показывает подключённое состояние.
6. Перезагрузка с включённым VPN: подключение поднимается до входа пользователя.
7. Обновление с 1.3.1: старый `Boop.exe` запускается, UAC один раз, задача планировщика «Boop VPN» исчезла, автозапуск
   работает через `Run`, токен и настройки на месте.
8. Обновление 1.4.0 → следующая версия из окна: служба перезапускается, окно стартует заново.
9. `Boop.exe --uninstall-service`: служба, файлы в `%ProgramFiles%\Boop` и `%ProgramData%\Boop` убраны, адаптера `Boop` нет.
10. Права: обычный пользователь не может записать в `%ProgramFiles%\Boop` и `%ProgramData%\Boop`.
