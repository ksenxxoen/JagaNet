# 1.5.1

Подзадача C-3 эпика #76 (Tauri 2 + Go-служба). Для человека ничего не меняется: установка, окно, вход,
серверы, «Не через VPN» — те же. Меняется то, кто делает системную работу: **только установщик**
(`installer/boop.iss`). Ни окно, ни служба ничего не регистрируют.

## Установщик

- Каталог `%ProgramFiles%\Boop`: права — `Permissions:` в `[Dirs]` (`system-full admins-full users-readexec`),
  владелец не меняется. `%ProgramData%\Boop` закрывается `icacls /inheritance:r` (только SYSTEM и администраторы).
- `wintun.dll` — файл из установщика, с исходной подписью Wintun (`build/wintun.dll`, его кладёт `build.sh`).
  В `BoopService.exe` он больше не вшит.
- Служба `BoopVPN`: `sc.exe create`/`config` (LocalSystem, автозапуск), `failure` (перезапуск), `start` — из `[Code]`
  установщика. Над 1.4.x служба перенацеливается на `BoopService.exe`.
- Автозапуск: значение `BoopVPN` в `HKCU\...\Run` (`"…\Boop.exe" --tray`), запись `[Registry]` по галочке.
  HKCU, а не HKLM: настройка личная, окно переключает её без прав администратора. Над существующей установкой
  галочка стоит так, как было у человека (значение Run или старая задача).
- Удаление: остановка и удаление службы, задача планировщика `Boop VPN` и Run-значение, файлы. Данные в
  `%LOCALAPPDATA%\Boop` остаются (опция «удалить данные» / `/PURGEDATA`).
- Обновление поверх 1.4.x: служба останавливается (`CloseApplications` закрывает окно), файлы заменяются,
  служба перерегистрируется на `BoopService.exe`, старая задача планировщика удаляется, один UAC.

## Что удалено из кода

`SecureDir`, `enablePrivilege` (`SeRestore`/`SeTakeOwnership`), флаги `--install-service`, `--uninstall-service`,
`--remove-service`, `--result`, `--autostart-on/off`, `MigrateAutostart`, вызовы `schtasks.exe`, `go:embed wintun.dll`,
регистрация службы (`winsvc.Install` и вся `System`). `BoopService.exe` знает только `--service` и `--version`.

## Портативный режим

Копия вне `%ProgramFiles%\Boop` (например, из «Загрузок») ничего не регистрирует и не распаковывает: ни
службы, ни автозапуска, ни ключей тостов, ни файлов рядом с exe. Если службы нет, при попытке подключиться
окно говорит об этом и открывает страницу установщика (`<панель>/download/windows`, как для обновления).
Переключатель автозапуска в такой копии отвечает ошибкой.

## Автозапуск из окна

Единственная точка записи — `winsvc.User` (реестр через API, без `reg.exe`/`schtasks`/`powershell`), и только для
установленной копии (`winsvc.InstalledCopy`).

## Версия и 1.4.x

Как и 1.5.0, версия 1.5.1 **не должна** попадать в поля `desktop.json`, которые читает 1.4.x; публикацию и сервер
эта задача не трогает. 1.5.1 доставляется установщиком.

## Сводка

Версия `1.5.1`: `build.sh`, `winres/*.json`, `installer/boop.iss`, `installer/build.ps1`.
