# Boop 1.2.0 для Windows: проверка перед выпуском

## Автоматически (Linux, без Windows)

```sh
cd desktop
go vet ./... && GOOS=windows GOARCH=amd64 go vet ./... && go test -race ./...
./build.sh 1.2.0-dev https://boopvpn.app      # собирает dist/Boop.exe
node scripts/ui-checks.mjs                     # поведение окна на выдуманных состояниях
node scripts/e2e.mjs                           # весь клиент на фейках, ~3 мин
SHOT_VP=360x520,1280x800 SHOT_SCALES=1,1.5 node scripts/screenshots.mjs docs/screenshots/<N>
```

Что e2e **не** может проверить без Windows: настоящий AmneziaWG и WFP kill switch, DPAPI,
трей и balloon-уведомления, автозапуск, установку обновления, DPI/мониторы. Это — ниже.

## Вручную на Windows 10 и Windows 11

Перед началом: чистый профиль (`%LOCALAPPDATA%\Boop` удалить) и второй прогон поверх
установленного 1.1.0 (старый `state.json`, в том числе с `lang: "en"`).

**Запуск и окно**
- [ ] Boop.exe запрашивает права администратора, окно открывается без белой вспышки.
- [ ] Окно меняет размер; меньше 360×520 не сжимается; на широком окне справа панель стран.
- [ ] Размер и позиция запоминаются после перезапуска; если второй монитор отключён — окно на основном экране.
- [ ] 100 %, 125 %, 150 %, 200 % масштаба: текст чёткий, ничего не обрезано; перенос окна между мониторами с разным DPI — без «прыжков».
- [ ] Светлая и тёмная тема Windows; смена темы при открытом окне.
- [ ] Иконки трея чёткие на 100–200 % во всех состояниях (выкл / подключение / вкл / проблема).

**Вход и выход**
- [ ] Вход по почте (6 цифр отправляются сами), неверный код — текст под полем.
- [ ] Вход через сайт: код на сайте совпадает с кодом в окне, вход проходит без перезапуска.
- [ ] Вход по коду устройства из личного кабинета.
- [ ] «Выйти» спрашивает подтверждение, Esc отменяет; после выхода устройство пропадает из кабинета.

**Подключение**
- [ ] Подключение / отключение кнопкой и из меню трея; сайт показывает IP ноды.
- [ ] Смена страны и ключа во время подключения и при включённом VPN — остаётся один ключ на устройстве.
- [ ] Переименование ключа в диалоге (Enter сохраняет, Esc отменяет); имя меняется в кабинете.
- [ ] Выдернуть сеть при включённом VPN → «Нет сети…», вернуть сеть → «Подключено» без действий.
- [ ] Заблокировать UDP до ноды (правило брандмауэра) → через ~20 с «Сервер не отвечает…», «Самая быстрая» пробует другую ноду, через ~45 с интернет возвращается, проба мимо туннеля (#2) пишет «Похоже, ваша сеть блокирует VPN. Попробуйте Wi‑Fi или другую страну.» с кнопкой «Другая страна» и тем же уведомлением в трее; в `boop.log` строка `probe: no_handshake: panel=yes web=yes … -> blocked`; через 30 с новая попытка.
- [ ] То же с «Не возвращать интернет, пока нет VPN»: интернет остаётся закрыт, а проба всё равно проходит (сокеты Boop.exe разрешены WFP) — текст «Похоже, ваша сеть блокирует VPN… Интернет закрыт, пока VPN не подключится.».
- [ ] Выдернуть кабель / выключить Wi‑Fi, затем включить VPN → после бюджета «Нет сети, пробуем снова…» без кнопки, в логе `-> offline`.
- [ ] В `boop.log` строки `probe:` не чаще раза в 30 с, без токенов и адресов.
- [ ] Остановить ноду при подключении → «Связь с VPN пропала…», переподключение.
- [ ] Тариф закончился → «Проблема», кнопка «Продлить» открывает оплату.
- [ ] Удалить выбранный ключ в кабинете → уведомление «Ключ удалён», переход на «Автоматически».
- [ ] Завершить сессию в кабинете → окно возвращается на вход.
- [ ] Автозапуск с Windows + «Подключаться при запуске»: после перезагрузки VPN поднимается сам (в том числе без сети в первые секунды).
- [ ] Панель недоступна при запуске → подключение по сохранённому конфигу.

**Обновление**
- [ ] Опубликовать тестовый манифест с версией выше: баннер «Доступно обновление», загрузка, проверка SHA-256, перезапуск в новую версию; повреждённый файл — «Не удалось обновить. Повторить».

**Сообщить о проблеме (issue #11)**
- [ ] Настройки → «Сообщить о проблеме» → комментарий → «Отправить»: «Отчёт отправлен» и номер; отчёт виден в админке (вкладка «Отчёты о проблемах»), в нём версия Windows (например «Windows 11 (10.0.22631)»), нода, адреса, рукопожатие, последние строки `boop.log`; ключей, токенов и ссылок `/k/` нет.
- [ ] Текст отчёта сразу в буфере обмена: вставляется в Блокнот с переносами строк.
- [ ] Без сети к панели (или шестой отчёт за час): «Не удалось отправить», файл `boop-report-….txt` лежит в `%LOCALAPPDATA%\Boop`, «Скопировать» снова кладёт текст в буфер.
- [ ] При проблеме на главном экране под текстом есть «Сообщить о проблеме».
- [ ] Через 10 минут подключения в `boop.log` строка `stats: node …, on, handshake …s ago, rx +… tx +… in 10m0s`.

**Клавиатура и доступность**
- [ ] Tab проходит по всем элементам, фокус виден; Esc закрывает листы и диалоги; фокус не уходит из открытого листа.
- [ ] Экранный диктор читает кнопку подключения, статус и кнопки-иконки.

## Черновик changelog 1.2.0 (не публиковать)

**Boop 1.2.0 для Windows**

- Новый дизайн: одна дизайн-система, светлая и тёмная тема по настройкам Windows, понятные состояния кнопки подключения.
- Окно можно растягивать: от компактного до широкого с панелью стран сбоку; корректно на 100–200 % масштаба и при смене монитора, размер и позиция запоминаются.
- Интерфейс только на русском.
- Поиск по странам, переполненные страны видны, но недоступны.
- Переименование ключа и подтверждение выхода — в самом окне.
- Под кнопкой подключения — причина проблемы и действие: «Продлить», «Войти», «Сменить страну».
- Если VPN молчит, Boop проверяет сеть мимо туннеля и различает «нет интернета» и «сеть блокирует VPN» — с кнопкой «Другая страна».
- Ошибки входа показываются под полем, а не всплывающим сообщением.
- «Сообщить о проблеме» в настройках и рядом с текстом проблемы: отчёт о подключении и журнал уходят в поддержку одним нажатием, без ключей и токенов; текст отчёта копируется в буфер обмена.
- Исправлено: после снятия проблемы её текст иногда оставался на экране; переключатель «Не возвращать интернет, пока нет VPN» после выключения снова показывался включённым; после выхода мог оставаться тариф прошлого аккаунта.
- Внутри: код клиента разделён по ответственности, мост окна описан и покрыт тестами, добавлены сквозные тесты.
