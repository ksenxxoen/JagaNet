# Дизайн-система окна Boop

Язык интерфейса один — русский. Тексты лежат в разметке `index.html` и в объекте `TXT` (`app.js`); словарей других языков нет.

CSS собирается в `ui.go` из трёх файлов в таком порядке:

| файл | что внутри |
| --- | --- |
| `tokens.css` | переменные: цвета, отступы, типографика, формы, размеры, анимации, слои |
| `components.css` | общие компоненты (классы ниже), сброс, фокус, ключевые кадры |
| `app.css` | раскладка экранов: вход, главный экран, настройки |

Правило: в `components.css` и `app.css` цвета, отступы, радиусы, тени, длительности и z-index берутся только из токенов. Новое значение — сначала токен.

## Токены

**Цвет** (тёмная тема по умолчанию, светлая — `prefers-color-scheme: light`): `--bg`, `--surface`, `--surface-2`, `--line`, `--text`, `--text-2` (вторичный текст), `--accent`/`--accent-2` (подсветка, градиент), `--accent-btn` + `-hover`/`-active` (фон кнопки, текст на нём `--on-accent`), `--success`, `--warning`, `--danger`, `--danger-bg`, `--btn-off` (кнопка подключения выключена), `--focus`, `--overlay`. Контраст текста и ключевых элементов не ниже WCAG AA (4,5:1 для обычного текста; кнопки с белым текстом на `--accent-btn` — ≥ 4,5:1 в обеих темах, в том числе при наведении и нажатии).

**Отступы** (rem, от корня 16 px): `--s-1` 4, `--s-2` 8, `--s-3` 12, `--s-4` 16, `--s-5` 24, `--s-6` 32, `--s-7` 48.

**Типографика**: `--fs-xs … --fs-xl`, `--fs-code` через `clamp()`; начертания `--fw-regular/medium/semibold/bold`; межстрочные `--lh-tight`, `--lh-base`; шрифт `--font` (Segoe UI Variable).

**Форма**: `--r-sm/md/lg/full`, `--border`. **Тени**: `--shadow-1`, `--shadow-2`, `--shadow-knob`. **Размеры**: `--control-h`, `--row-h`, `--item-h`, `--icon-btn`, `--flag`, `--boop` (диаметр главной кнопки, `clamp` по `vmin`), `--content-w` (ширина колонки на широком окне).

**Анимации**: `--dur-fast` / `--dur` / `--dur-slow`, `--dur-wave`, `--dur-spin`, кривые `--ease`, `--ease-pop`. При `prefers-reduced-motion: reduce` длительности сводятся к нулю, волны и вращение отключаются.

**Слои**: `--z-banner` 5, `--z-sheet` 10, `--z-dialog` 15, `--z-toast` 20.

## Компоненты

| класс | назначение |
| --- | --- |
| `.btn` + `.btn-primary` / `.btn-secondary` / `.btn-text` / `.btn-danger` | кнопки |
| `.icon-btn` | кнопка-иконка (настройки, закрыть) |
| `.card`, `.card-link` | карточка; кликабельная карточка (текущая локация) |
| `.list-item` (+ `.selected`), `.item-text/-title/-sub/-action`, `.check` | элемент списка стран и ключей |
| `.group`, `.setting-row` (+ `.is-link`, `.is-danger`, `.switch-row`) | группа и строка настроек |
| `.switch` + `<i>` | переключатель (нативный чекбокс, виден фокус) |
| `.banner` | баннер обновления |
| `.toast` | всплывающее сообщение |
| `.sheet`, `.sheet-head`, `.sheet-list` | лист на весь экран (страны, ключи, настройки) |
| `.dialog-wrap`, `.dialog` | диалог по центру (переименование ключа) |
| `.field`, `.input`, `.input-code` | поле ввода с подписью |
| `.badge` (+ `.is-ok`, `.is-warn`) | бейдж статуса («Используется») |
| `.flag`, `.ping` | флаг страны, качество пинга (`data-q` 1–3) |

Доступность: видимый фокус (`:focus-visible`, цвет `--focus`) у всех элементов, листы и диалоги — `role="dialog"` + `aria-modal`, при открытии фокус уходит в лист и возвращается назад, `Esc` закрывает; статус подключения — `aria-live`.

## Главный экран

Колонка по центру шириной до `--content-w`; раскладка на flex, размеры в `rem`/`vmin`/`%`.

Кнопка подключения (`#boop`, `data-state`):

| состояние | вид | подпись |
| --- | --- | --- |
| `off` | серая | «Выключено» + «Нажмите, чтобы подключиться» |
| `connecting` | вращающееся кольцо, акцент | «Подключение…» |
| `reconnecting` | то же | «Переподключение…» |
| `on` | заливка акцентом, волны | «Подключено» + таймер |
| `problem` | кольцо и подпись цвета `--warning` | «Проблема», пояснение и одна кнопка по коду проблемы |

Кнопка под статусом (`#detail-btn`, `dataset.action`): `plan` → «Продлить» (`extend`); `auth` → «Войти» (`signOut`, открывает вход); `key_removed` → «Выбрать ключ» (лист ключей); `no_handshake`, `dead` → «Сменить страну» (лист стран); `offline` — без кнопки.

Карточка локации внизу: флаг, страна, имя выбранного ключа, пинг; открывает лист выбора страны. Шестерёнка справа вверху — настройки. Баннер обновления — над содержимым.
