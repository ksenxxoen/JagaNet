# 1.4.4

- Уведомления на Windows 10 (1809+) и 11 — настоящие Toast (WinRT) с иконкой Boop и названием
  «Boop VPN»; остаются в Центре уведомлений. Вместо старых balloon-подсказок трея.
- Кнопки там, где они нужны:
  - «VPN отключился / нет соединения» → «Переподключить», «Открыть»;
  - «Тариф заканчивается / закончился» → «Продлить» (та же страница тарифов, что в окне), «Открыть»;
  - «Доступно обновление» → «Обновить», «Позже».
  Тело уведомления открывает окно. Кнопки вызывают те же команды, что кнопки окна и трея
  (`App.Act` в `core/notify.go`): «Повторить»/подключение, «Продлить», «Обновить».
- Если Toast недоступен (старая Windows, ошибка WinRT, уведомления выключены) — как в 1.4.3, balloon.
  Linux не меняется.
- Тексты, поводы и частота уведомлений прежние (каждая проблема один раз, предупреждение о тарифе —
  раз в день на уровень). В уведомлениях и журнале нет ключей, UUID и адресов нод.
- AppUserModelID `Boop.VPN`: ярлык «Пуск» из установщика, а без установщика клиент сам пишет
  `HKCU\Software\Classes\AppUserModelId\Boop.VPN` (имя, иконка) — без прав администратора.
- Установщик: `AppUserModelID` у ярлыка, регистрация ключей от имени пользователя
  (`Boop.exe --toast-register`), удаление при деинсталляции (`--toast-unregister`).
- Версия по умолчанию в `build.sh` исправлена с 1.4.1 на 1.4.4.
