# Boop 1.3.0: проверка перед выпуском (Windows 10/11, Ubuntu 22.04/24.04)

## Автоматически (Linux, без Windows) — сделано в PR выпуска

```sh
cd desktop
go vet ./... && GOOS=windows GOARCH=amd64 go vet ./... && go vet -tags boopapp ./...
go test -race ./... && go test ./vpn/xray/
node scripts/ui-checks.mjs && node scripts/e2e.mjs
./build.sh 1.3.0 && BOOP_INSTALL_TEST=1 ./build-linux.sh 1.3.0
```

e2e и ui-checks покрывают на фейках: вход тремя способами (в том числе код с устройства для
аккаунта из Telegram), заблокированный аккаунт, «Пригласить друга», тариф, статусы нод, отчёт о
проблеме, VLESS-ноды в списке (dev-сборка), молчащий сервер. Не могут проверить: настоящий
туннель и kill switch, трей, DPAPI, автозапуск, установку обновления, DPI — это ниже.

Перед началом: чистый профиль (`%LOCALAPPDATA%\Boop` / `~/.config/boop` удалить) и второй прогон
поверх установленного 1.2.0 (старый `state.json`).

**Подключение**

- [ ] То же с «Не возвращать интернет, пока нет VPN»: интернет остаётся закрыт, а проба всё равно проходит — текст «…Интернет закрыт, пока VPN не подключится.».

- [ ] Тариф закончился → «Проблема», кнопка «Продлить» открывает тарифы на сайте (`/#pricing`).
